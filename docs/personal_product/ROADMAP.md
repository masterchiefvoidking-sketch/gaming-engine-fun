# Roadmap (Post Personal Product Cut)

Personal product cut completes the first offline, single-player build. Future work is optional and out of scope for RC1:

1. GUI editor viewport with live character preview
2. GPU post-process pipeline (bloom, DOF, color grading)
3. Skeletal animation import and retargeting
4. Full wardrobe UI with rendered thumbnails
5. Texture compression in asset cooker
6. CI performance regression gates

**Not planned:** multiplayer, console, marketplace, cloud accounts, ads, analytics, DRM, or external login.
