# Character Customization Guide

## Mira (Original Character)

The demo ships one original adult anime-style female character: **Mira**.

- Definition: `Game/ApartmentLifeDemo/Assets/Characters/mira.json`
- Profile data: `data/apartment_life/romance_sim/character_profile.json`

## Customization

| Feature | Location |
|---------|----------|
| Body preset | Character editor |
| Hairstyles (5+) | `Assets/Characters/Hairstyles/` |
| Expressions (10+) | `Assets/Characters/Expressions/` |
| Outfits (20+) | `Assets/Characters/Wardrobe/` |

## In-Game

Use the wardrobe room to change outfit, hair, and expression. Changes persist through save/load.
