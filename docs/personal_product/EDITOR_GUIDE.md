# Editor Guide

## Opening a Project

1. Launch **EVE Creator Studio**
2. Open `Game/ApartmentLifeDemo`
3. Confirm character, wardrobe, dialogue, and event counts in the console

## Panels

| Panel | Purpose |
|-------|---------|
| Character Editor | Edit Mira body, face, and metadata |
| Wardrobe Editor | Add or tune outfit items |
| Apartment Builder | Place furniture and define rooms |
| Dialogue Graph | Edit conversation nodes |
| Event Graph | Edit scene events and conditions |
| Export Panel | Validate, cook, and export builds |
| Photo Studio | Capture screenshots with presets |

## Workflow

1. Edit content in panels
2. Save project (`save_project`)
3. Validate via Export panel
4. Test play with Apartment Life Demo app
5. Export Windows and Web targets
