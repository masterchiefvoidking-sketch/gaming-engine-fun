# Wardrobe Guide

## Content

Apartment Life Demo includes 20+ original wardrobe items for Mira.

## Categories

Items are defined in `Assets/Characters/Wardrobe/mira_outfit_XX.json` and indexed in `data/anime/wardrobe_items.json`.

## Editor

Use the Wardrobe Editor panel in Creator Studio to add items. Each item needs:

- Unique `id`
- `category` (top, bottom, dress, etc.)
- Compatible mesh/material references

## In-Game

Enter the wardrobe room and interact with the closet to change outfits. Outfit state is saved with the game.
